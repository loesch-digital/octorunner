## See which runners match a queued job

Open **Jobs & Workflow Runs**, choose a workflow run, and expand a queued self-hosted job. OctoRunner shows which observed repository runners match the job’s labels and whether GitHub reports them idle, busy, or offline. The hint shows when observations are unavailable or out of date. It includes the job’s age when GitHub supplies its creation time.

The hint uses existing GitHub observations and permissions. GitHub still assigns jobs.

## Install or update

```sh
brew install --cask loesch-digital/tap/octorunner
```

Already installed? Run `brew update` and then `brew upgrade --cask octorunner`.
