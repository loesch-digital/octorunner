## Workflow details open reliably

Fixed a macOS accessibility crash when opening workflow details from a runner card or from **Jobs & Workflow Runs**. VoiceOver can identify the job disclosure, the log button, the GitHub link, and the steps individually.

## Install or update

```sh
brew install --cask loesch-digital/tap/octorunner
```

Already installed? Run `brew update` and then `brew upgrade --cask octorunner`.
