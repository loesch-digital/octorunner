# OctoRunner v0.5.0-beta.1

This preview is for acceptance testing of the Settings and Jobs work ahead of the full v0.5.0 release.

## What's in This Preview

- Fixed a menu bar launch hang. The status label uses a cancellable refresh task. A native regression test verifies that the main thread responds after the scene starts.
- Settings categories show icons and labels and wrap onto multiple rows in narrow windows. Content is grouped into cards with headings and explanations. Settings search works in German and English and opens the matching category.
- The menu bar shows the OctoRunner logo and a locally observed status dot, with distinct icon shapes when **Differentiate without color** is enabled. The app detects active jobs running from versioned binary directories after runner self-updates. The dashboard and runner wizard adapt to smaller windows and long lists. Open the console when needed.
- Native settings for General, Autostart & Background, Failover, Auth & Tokens, and Notifications are also available from the main window. New LaunchAgents apply the configured restart policy, delay, and PATH.
- Native macOS notifications are opt-in and cover local status changes, newly detected job failures, and low disk space. Job failures require a matching repository source and a unique local runner match. Only failures completed after the opt-in baseline can trigger alerts. Monitoring runs while the GUI is running.
- Job history includes filters, queue status, per-account persistence, paginated details, and metrics from available data. Heavy job traffic or long offline periods can exceed the polling window.
- Improved account and Keychain handling and added verified SHA-256 checksums for runner downloads, including when the Downloads API omits the checksum.
- The runner wizard includes collapsible German and English help for workspace variables, a copyable Fastfile example, and targeted cleanup. The runner name prefix and shared workflow labels are separate inputs.
- Runner configuration and LaunchAgent registration wait asynchronously and report registration failures. Canceled or superseded migrations leave models intact. Full migration transactions with rollback follow in the engine milestone.

## Remaining Work

The Cache & Storage tab with safe automatic cleanup and log retention, full global concurrency and drain policies, expanded host telemetry (I/O and process inspector), the audit dialog, and complete localization remain in progress. Full supervision, crash and quarantine policies, and sync follow in v0.6.0. Update installer verification and recovery are planned for release readiness. Use the ZIP for this preview.

## Installation and Acceptance

The beta ships as a Developer ID-signed, notarized ZIP alongside the stable Homebrew cask and stable Latest release. Download `OctoRunner-0.5.0-beta.1-arm64.zip` from this release's assets. Apple Silicon and macOS 15 or later are required.

Quit any running copy, extract the ZIP, and open the app in Finder. Gatekeeper must accept notarization with quarantine attributes intact. Debug, beta, and stable builds share the same bundle ID, database, preferences, and Keychain. Test under a separate macOS user with test runners if you need isolated data.

1. Launch and verify that startup does not prompt for Documents access. Open the dashboard repeatedly and confirm that only one window opens.
2. Check the menu bar status, close and reopen the window, and test the Quit confirmation.
3. Resize the main window and **New Runner** wizard with many repositories and labels. Expand workspace help and copy the example.
4. Open Settings from the main window and via `⌘,`. Check German and English, and Light and Dark. Perform authentication actions on the intended test account.
5. Load jobs for a test repository, filter them, and open details. After opting in to notifications, trigger a new failure on a matching test runner. Historical failures should stay silent.

The associated pull request records automated checks and specific CI and release runs. Interactive acceptance is a separate gate.
