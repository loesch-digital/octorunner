# OctoRunner v0.7.0

OctoRunner improves recovery from failed app updates and enables macOS notifications for directly managed runner failures.

## Updates and recovery

- OctoRunner verifies the downloaded bundle's version and signature and asks macOS to assess it before installation.
- The installer keeps the previous app and a backup of the local database until the replacement opens the database and confirms startup. A failed launch restores the previous version and database.
- OctoRunner shows update and recovery messages in English and German. If recovery needs manual attention, preserve the backups and follow the recovery guide.

## Notifications and documentation

- Enable runner error notifications in **Settings → Notifications**. Repeated observations of the same fault produce one notification.
- The new English README includes installation, Xcode, and GitHub permissions instructions alongside screenshots from the app. OctoRunner is licensed under Apache License 2.0.

## Install on Apple Silicon

OctoRunner requires macOS 15 or later. For the first upgrade from v0.6 or earlier, use Homebrew or the signed ZIP from this release. Users of the previous Homebrew tap can follow the one-time migration instructions.

```sh
brew install --cask loesch-digital/tap/octorunner
```
