## Local runner monitoring after you quit

OctoRunner can keep checking registered runner processes after you quit the app. Enable **Monitor local runners after quitting** under **App Settings → Autostart & Background**.

- **macOS 27 and later.** After you quit, the Dock shows **Running in Background**. Reopen OctoRunner from the Dock or choose **Stop Running in Background** to end the monitoring session.
- **Earlier supported macOS versions.** Manage the OctoRunner background helper under **System Settings → General → Login Items & Extensions**.

GitHub refreshes and OctoRunner notifications run while the app is open. Independently configured runner services follow their own launch settings.

## Install or update

```sh
brew install --cask loesch-digital/tap/octorunner
```

If you already have OctoRunner installed, run `brew update` and then `brew upgrade --cask octorunner`.
