## See CPU, RAM, and work folder size per runner

The **Runners** dashboard shows current CPU and RAM for detected runner processes. Select **Measure Work Folder** on a runner to measure the size of its configured work folder. You can refresh the result after a job or cleanup.

## Install or update

```sh
brew install --cask loesch-digital/tap/octorunner
```

Already installed? Run `brew update` and then `brew upgrade --cask octorunner`.
