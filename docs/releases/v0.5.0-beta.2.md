# OctoRunner v0.5.0-beta.2

This beta builds on v0.5.0-beta.1. The stable Homebrew release remains v0.4.4 while work on v0.5.0 continues.

## What's New

- Runner availability and the last workflow result have separate indicators. Running is consistently blue. A failed job remains visible as the latest result and can be acknowledged.
- **Cache & Storage** analyzes managed runner directories and previews cleanup. You can confirm a cleanup or configure automatic policies. Imported external runners are excluded from automatic cleanup.
- **Audit Log** supports combined filters, a search of saved history, full event details, and JSON export of the displayed events. It includes app, update, and local process status events.
- **Host Telemetry** shows total CPU load, detected performance and efficiency core counts, memory breakdown, volume capacity, device I/O, and the active account's last observed GitHub API budget. Cards adapt to the window size, and the sample interval is configurable.

## Planned for v0.5.0

The per-runner process inspector, further telemetry improvements, and global concurrency control are in development. Telemetry shows available measurements and displays an em dash for missing values. Per-core-type CPU load requires a verifiable mapping.

## Try the Beta

1. **Runners and menu bar.** Running is blue. After a job fails, its result remains visible when the runner returns to Idle.
2. **Audit Log.** Search or filter the history, open an event, and export displayed events as JSON. The app asks for a save location when you export.
3. **Host Telemetry.** Resize the window, select a sample interval, and refresh. CPU load requires two samples. The API budget comes from the Jobs view and shows the age of the measurement.

The signed and notarized zip works without Homebrew. Stable, beta, and Debug builds share local data. Run one copy at a time. The local Debug display version was still 0.1.0 at this point. The release bundle shows the full beta version.
