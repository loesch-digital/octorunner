## Changes

- See the number of running GitHub Actions workflows in the sidebar. Running workflows, jobs, and steps show elapsed time when GitHub provides a start time.
- Open the current workflow and job from a busy local runner when GitHub reports a matching assignment. The last completed job result remains visible separately.
- History sources now opens in a dialog so the sidebar stays available when you close it.
- Runner process IDs and workflow run IDs are displayed without digit grouping.
- The Dock menu shows when monitoring continues after the last window closes and the Dock icon stays visible.
